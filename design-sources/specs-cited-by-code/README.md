Ten specs that the CODE points at by name.

Code comments across this repo cite 73 `for-claude-code-*.md` documents. Most of
those were read once and thrown away, and the project has been fine, because the
comments quote the part that mattered. These ten are the ones that (a) are cited
in a comment somewhere and (b) still existed anywhere on 17 Sep 2026 -- they came
off Ramy's Desktop, out of the zipped handoffs, before those were cleared.

They are here so a citation leads somewhere. They are NOT a to-do list: every
item in every one of them is built, deployed and verified. Where two versions of
the same document arrived, this is the last one.

If one of these is ever superseded by a new handoff, replace it rather than
keeping both -- see the "delete superseded specs" note in memory. A stale spec
sitting beside a current one is the thing that rule exists to prevent.
