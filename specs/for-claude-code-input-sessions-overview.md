Written 15 Aug 2026, for Claude Code. Companion to `for-claude-code-text-based-teaching.md` (Text-Based Teaching has its own full spec) and `for-claude-code-trainer-in-training.md` (Classroom Management is specified there). This file covers the 16 other input sessions already built as design files — the source of truth is each `.dc.html` file; this is the index and shared shape, not a rewrite of the content.

## Shared shape (most sessions)
Most sessions in this list follow the same five/six-part loop-input shape also used by PPP and Text-Based Teaching: lead-in → match key terms → predict the staging → read/listen and check ideas → detail questions → debrief (reorder the stages or discuss) → trainer notes. Where a session departs from that shape (Sounds, Stress and Intonation, MFP, Lesson Planning, Lesson Framework, Language Analysis, Connected Speech, Checking Meaning), its own agenda below is the actual structure — build from that, not the shared shape.

## Notes carried from the files themselves
- **Lesson Planning**: the draft made in-session is explicitly *not* saved or submitted — trainer note in the file: "the draft isn't the submission... today's forty-five minutes just builds the habit." Language analysis is deliberately absent from this session since TP2's point already supplies the target language.
- **MFP**: uses a "spot the flaw" format — three flawed sample lesson plans (present perfect, third conditional, polite requests), each with a hidden fix revealed on demand.
- **Connected Speech**: five phenomena (strong/weak forms, linking, intrusion, assimilation, elision), three examples each, each example a two-option pick with a spoken explanation.
- **Stress and Intonation** and **Language Analysis** connect explicitly back to FOL (Focus on the Learner) and each candidate's own TP point rather than a generic text.
