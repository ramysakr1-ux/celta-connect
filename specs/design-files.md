## Phonology input sessions (Resource Hub)
`Sounds Input Session.dc.html`, `Stress and Intonation Input Session.dc.html`, `Connected Speech Input Session.dc.html` — 45-minute interactive sessions, browser speech synthesis (Chrome exposes Google’s natural voices), each with a print fallback (Print button switches to a plain answer-key layout for paper/face-to-face use) and an explicit "Where this feeds back in" box tying the session to FOL and LRT. Sounds includes a link to Seeing Speech (seeingspeech.ac.uk) for real articulation video.
