How to use this

  1. Adjust an existing role: click any pill in the table to cycle it Full → View → None. Each cell is independent, so mix and match freely.
  2. Add a capability that isn't listed: type its name in "Add a capability…", pick who should get it, then click Add capability.
  3. Add a whole new role (e.g. Centre Director): type its name under "Add a new role" and click Add role — it appears as a new column, starting at None everywhere, ready to configure the same way.
  4. Check your work: the "Preview" cards below update live to show exactly what each role's description will read on the Roles tab.
  5. Nothing here can ever grant course chat, grading, or candidate work — those stay trainer-only no matter what you set.
