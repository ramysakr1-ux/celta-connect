Desktop shortcuts, one per role
A shortcut somebody saves to their desktop or dock goes straight to their own room — a candidate to Course Stream, a tutor to Today, a volunteer to their group. Same mark every time; the colour and the badge letter say whose it is.
The whole problem is the small sizes. A 16px favicon is 16 pixels; the double arc that reads at 128 turns to mud. So each icon has two drawings — the full mark down to 32px, a single arc below it — and the badge disappears entirely under 48px, where a 6px letter is noise.

What this needs to become real
A shortcut per role means a manifest per role — src/app/manifest.ts is currently one file with one start_url, so all six would install as the same app. Each role needs its own manifest route, its own start_url, and PNGs at 192 and 512. Tell me which roles you actually want and I'll write that spec.
One correction to flag: the manifest's own comment says background_color: "#faf7f2" is --color-background at oklch(97.8% 0.008 85). That was the old ground — the page has been oklch(92.5% 0.012 85) since 16 Aug, so every splash screen opens a shade too light.
