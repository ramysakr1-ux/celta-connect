Listening — taught the way you'll teach it.
This session is staged exactly like the lesson it teaches: pre-taught vocab, a discussion of how listening should be taught, then listening to a dialogue to check those ideas. Do the tasks first — the debrief afterward is where it gets named.
Running this session
Don't name "listening" or its stages until the debrief. The audio track is browser text-to-speech, not a real recording — flag that once, then play it exactly as many times as each task says, no more.
